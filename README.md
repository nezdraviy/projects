# Used Cars Dataset 
**Ссылка на датасет:** https://www.kaggle.com/datasets/taeefnajib/used-car-price-prediction-dataset

Данный датасет использовался для решения задачи регрессии по предсказанию цены подержанного автомобиля. В ходе исследования датасета было предложено несколько гипотез:
1) При кодировании признака 'brand' стоит выбирать не более чем топ-7 категорий для OneHotEncoder (число категорий может подбираться как гиперпараметр). В противном случае OHE приведет к переобучению.
2) Линейная модель регрессии будет справляться не хуже, чем дерево решений, поскольку количество данных небольшое (~4000).
3) Наиболее важными признаками дерева будут 'milage', 'model_year' и 'accident'.
4) Для линейной модели L2 регуляризация будет работать лучше, чем L1, поскольку количество признаков в выборке небольшое, а шумовые удаляются на этапе EDA.
5) CatBoost даст наилучший результат ввиду самого алгоритма работы "из коробки" с категориальными признаками.
